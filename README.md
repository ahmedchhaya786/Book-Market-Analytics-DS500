# Book Market Analytics – Books to Scrape

**Course:** Data Science 500  
**Project:** Book Market Analytics – Books to Scrape

## Project overview
This project scrapes book catalogue information from [Books to Scrape](https://books.toscrape.com/), cleans the data, explores pricing patterns with visualisations, and trains a linear regression model to estimate book prices.

## Assignment deliverables
- `notebooks/book_market_analytics.ipynb` — end-to-end notebook.
- `data/books_dataset.csv` — generated by running the scraping notebook/script.
- `reports/` — the notebook creates a report summary after analysis.
- `src/scraper.py` — reusable scraping code.
- `requirements.txt` — Python dependencies.

## Requirements
Python 3.10+ is recommended.

Install dependencies in the PyCharm terminal or a command prompt:

```bash
pip install -r requirements.txt
```

## Run the project
### Option A: Jupyter Notebook
1. Open the project folder in PyCharm.
2. Install the requirements above.
3. Open `notebooks/book_market_analytics.ipynb`.
4. Run the cells from top to bottom.
5. The notebook scrapes the catalogue, saves the cleaned CSV, creates charts, evaluates the model, and writes a report summary.

### Option B: Run the scraper only
From the project root:

```bash
python src/scraper.py
```

The scraper collects the book title, price in GBP, star rating, stock status and quantity where shown. It follows catalogue pagination and aims to collect all available books (the assignment minimum is 200). If the website is temporarily unavailable, try again later.

## Output files
- `data/books_dataset.csv` — cleaned data.
- `outputs/price_distribution.png`
- `outputs/average_price_by_rating.png`
- `outputs/price_vs_rating.png`
- `outputs/average_price_by_genre.png` (if genre data is available)
- `reports/project_report.md` — report summary created by the notebook.
